# SAC-llm
**Safety, Assistance, Convenience LLM**

SAC-llm은 안전성(Safety), 지원(Assistance), 편의성(Convenience)을 목표로 개발된 Windows 기반 인공지능 에이전트 프로젝트입니다.

## 다운로드

### SAC-llm Agent

- **배포 버전:** v8.0.4
- **플랫폼:** Microsoft Windows
- **아키텍처:** x64
- **배포 형식:** ZIP
- **배포 용량:** 약 488MB

[**SAC-llm Agent 다운로드 (Google Drive)**](https://drive.google.com/file/d/1wlYrPI6ApdOW5ebNOLWOPHf-Mo_FrXIH/view?usp=drive_link)

## 주요 시스템

### 메인 시스템
- **SAC GUI** – 사용자 인터페이스 시스템
- **SAC AI** – 인공지능 처리 시스템
- **SAC SECURITY** – 보안 및 안전성 관리 시스템

### 부가 시스템
- **SAC CODEP CORE** – 코드 처리 및 개발 지원 시스템
- **SAC PRO HUGGING** – Hugging Face 관련 연동 시스템

## 설치 방법

1. 위 다운로드 링크에서 SAC-llm ZIP 파일을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 해제합니다.
3. 압축 해제된 폴더에서 `SACllm.exe`를 실행합니다.
4. 프로그램이 정상적으로 실행되는지 확인합니다.

## 시스템 요구 사항

- 운영체제: Windows 10 / Windows 11
- 아키텍처: 64-bit (x64)
